Typography, brand, and review notes

DM Sans carries the body and headings. Instrument Serif adds a restrained contrast to the compact opening. IBM Plex Mono is reserved for dates and technical metadata. The original line-drawn DK mark is the secondary identity.

All artwork is original. The mark stands in for personal identity without fabricating a portrait. Real photography can be introduced when supplied. Project text is provisional; writing is explicitly marked as draft.

Light and dark themes use local fonts. Native links and project notes work offline without JavaScript.
